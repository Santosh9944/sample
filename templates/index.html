    About VerifAI

    VerifAI is a multimodal fake news detection system built as a Deep Learning project. It leverages state-of-the-art transformer models and computer vision techniques to identify misinformation across text, image, and video content.

    PyTorchTransformers BERTOpenCV FlaskELA Analysis NumPySciPy
    📝

    Text Analysis

    BERT transformer fine-tuned on fake news datasets with linguistic feature fallback

    🖼️

    Image Forensics

    Error Level Analysis (ELA), metadata inspection, and color channel consistency

    🎥

    Video Analysis

    Temporal frame sampling with inter-frame consistency and anomaly detection

    🔀

    Fusion Layer

    Confidence-weighted combination giving final probability and risk assessment
